OLOSPHERA — sito one-page (ultima versione)

APRIRE IN LOCALE
- Il sito carica file (frame, Ollie 3D) via rete: aprendo index.html con doppio clic alcuni browser bloccano il caricamento.
  Meglio un piccolo server locale, es. nella cartella:  python -m http.server 8000  → http://localhost:8000

PUBBLICARE
- Vercel / Netlify: trascina questa cartella → online in un minuto.
- Qualsiasi hosting: carica tutta la cartella (index.html + frames/ + loghi + ollie-*).

LIBRERIE ESTERNE (CDN jsDelivr)
- lenis@1.1.18 (scroll fluido) — se manca, la pagina usa lo scroll normale.
- three@0.147.0 (Ollie 3D) — se manca o WebGL non c'è, dopo 9 s compare Ollie 2D (ollie-body.png).
